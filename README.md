# Faustas Rinkevičius – CV svetainė

Svetainė tęsiama pagal 7–9 laboratorinių darbų reikalavimus. Pagrindinis puslapis yra `index.html`.

## Peržiūra kompiuteryje

1. Atidaryk šį aplanką su Visual Studio Code: **File → Open Folder**.
2. Įdiek **Live Server** papildinį.
3. Atidaryk `index.html`, spustelėk jį dešiniuoju pelės mygtuku ir pasirink **Open with Live Server**.
4. Jei reikia, įdiek ir **Prettier – Code formatter** papildinį.

## LD8 turinys

- „Patirtis“ puslapyje pateiktos studijos, akademiniai darbai ir aiškiai nurodyta, kad profesinės patirties dar nėra.
- „Atlikti darbai“ puslapyje yra trys MATLAB grafikai su pavadinimais, aprašymais ir alternatyviais tekstais.
- „Paslaugos“ puslapyje pateikta 4 × 3 lentelė, technologijų sąrašas su įdėtiniu sąrašu, numeruoti analizės etapai ir HTML vaizdo, YouTube bei garso įrašai.
- Pexels vaizdo ir Pixabay garso failai saugomi `assets/media` aplanke.

Lentelėje nurodytos paslaugos ir kainos yra mokomieji pavyzdžiai, o ne realus kainoraštis.

## LD9 stiliai

- `assets/css/custom.css` po `main.css` prijungtas prie visų svetainės puslapių.
- Atnaujinta tipografija, spalvų kontrastas, nuorodos, mygtukai, tarpų dydžiai ir turinio blokai.
- Perdaryta navigacija ir „į viršų“ mygtukas; sąrašai atnaujinti pseudo-elementais bei skaitikliais.
- Paslaugų lentelėje naudojamas išskirtinis antraštės stilius, zebra eilutės, užvedimo efektas ir vienodas centruotas langelių turinys.

## LD10 CSS animacijos

- Skilčių antraščių `::before` ir `::after` pseudo-elementai animuojami atskiromis `@keyframes` taisyklėmis.
- „Paslaugų“ skiltyje yra CSS sukurtas besisukantis dekoratyvinis krovimo indikatorius ir judantis gradientinis fonas.
- „Apie“ skilties įžanginiame bloke yra dvi animuojamos CSS figūros: apskritimas ir trikampis.
- Animacijų judesiai ir spalvų švytėjimas sumažinami, kai įrenginyje įjungtas sumažinto judesio nustatymas.
